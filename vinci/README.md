# Vinci Casa

App da Vinci Automação (PWA): cenas da casa em uma tela, cômodos, controle remoto por cenas e comando de voz para o Félix.

Endereço: https://leandropor-glitch.github.io/jarvis-leandro/vinci/

- `index.html`: app (abas Cenas, Cômodos, Controles + barra do Félix).
- `comodos.json`: cômodos, cores (manual de marca Vinci 2024) e controles (botão → lista de nomes de cena).
- Backend: o mesmo do app Felyx (`/webhook/felix/app` e `/webhook/felix/pergunta` no n8n). Mesmo login.
